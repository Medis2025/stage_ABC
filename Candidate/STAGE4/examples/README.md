# Stage 4 Examples

This directory stores small example datasets for Stage 4 validation.

## `pilot_hpo_s3r_data`

The pilot example is a hand-sized S3R contract dataset with:

- 6 ontology nodes
- 2 evidence chunks
- 2 S1 span supervision rows
- 2 S2 retrieval rows
- 2 S3 rerank rows
- 4 abstention samples
- 5 graph edges

It is useful for validating references and offsets without running the full
Stage 1-3 pipeline.
